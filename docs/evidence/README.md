# Bằng chứng (evidence)

Lưu ảnh chụp và văn bản làm căn cứ cho các quyết định. Đặt tên theo mẫu `YYYY-MM-DD_noidung.png`.

Cần có:
- `2026-10-10_tomtom_dashboard_1.png`, `2026-10-10_tomtom_dashboard_2.png`: hạn mức TomTom (Traffic Flow Segment Data API: 20.000/tháng)
- `lecturer_confirmation.*`: xác nhận của giảng viên (API chính thức, định dạng nộp, có được công bố dữ liệu không)
- Ảnh chụp điều khoản TomTom về lưu trữ/chia sẻ dữ liệu (nếu có)

Không đưa API key, email, thông tin cá nhân vào ảnh (che trước khi lưu).
